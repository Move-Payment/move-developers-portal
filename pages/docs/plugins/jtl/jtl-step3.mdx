---
title: "Step 3: Set Up Payment Gateway Credentials"
---

Connect JTL to your business using credentials from the MovePayment Merchant App.

## Select Your Business

1. Log in to the **MovePayment Merchant App**.
2. Open the **Business** section and select the business you want to connect.
3. Copy the business's **Move ID**.
4. Return to the MovePayment plugin settings in JTL and paste it into the **Move ID** field.

   ![JTL MovePayment settings with the empty Move ID field highlighted](/plugins/jtl/move-id-field.png)

## Create and Enter an API Key

1. In the MovePayment Merchant App, navigate to **Other → API settings**.
2. In the **API Keys** section, click **Add API key**.

   ![MovePayment Merchant App API settings with the Add API key button](/plugins/jtl/merchant-api-settings.png)

3. Enter a **Description** and click **Save API key**, then copy the generated key. You can leave the expiration date blank; in that case, the key remains valid until it is revoked.

   ![Add API key dialog with Description and Expire at fields and the Save API key button](/plugins/jtl/add-api-key.png)

4. Return to the plugin settings in JTL and paste the key into **API Secret Key**.

   ![JTL MovePayment settings with the empty API Secret Key field highlighted](/plugins/jtl/api-secret-key-field.png)

For more details, see [Getting API keys](/docs/integration/api-keys).

## Configure Test Mode

To test the integration with the [MovePayment Sandbox](/docs/integration/sandbox), turn **Test mode** on. The setting is labeled **Test mode (logged-in admin only)** in JTL.

Click **Save** to store your settings, then continue to [configure the webhook and enable the payment method](/docs/plugins/jtl/jtl-step4).
