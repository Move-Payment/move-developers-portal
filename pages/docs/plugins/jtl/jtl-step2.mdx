---
title: "Step 2: Access Plugin Settings in JTL"
---

Open the MovePayment plugin settings to configure your payment gateway:

1. Log in to your **JTL Admin Dashboard**.
2. Navigate to **PLUG-INS → Installed plug-ins**.
3. Select **MovePayment** from the list of installed plugins.
4. Click **Settings**.

![MovePayment settings in JTL with empty Move ID, API Secret Key, and Webhook Secret Key fields](/plugins/jtl/plugin-settings.png)

This page contains the fields for your business, API credentials, webhook secret, test mode, and payment method display name.

Continue to [set up your payment gateway credentials](/docs/plugins/jtl/jtl-step3).
